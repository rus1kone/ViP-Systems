# VIP Systems Website

Responsive corporate website implementation for VIP Systems.

Built from an approved design and recreated as a clean, responsive front-end implementation using Vite, semantic HTML, modular CSS, and vanilla JavaScript.

## Tech Stack

- Vite
- HTML5
- CSS3
- Vanilla JavaScript
- Responsive Design

## Features

- Responsive desktop, laptop, tablet, and mobile layouts
- Interactive desktop mega menu
- Mobile navigation drawer and accordions
- Animated hero section
- Infinite logo and technology partner marquees
- Expandable solutions section
- Interactive DRIVE process section
- Industry cards and detail overlays
- Project gallery with lightbox views
- Responsive careers section
- Contact form UI
- Expandable office locations
- Modular section-based CSS architecture
